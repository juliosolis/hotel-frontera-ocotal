# Compatibilidad

- El servidor de producción usa Ubuntu 18.04 con PHP 7.2. Todo código PHP nuevo o modificado debe ser compatible con PHP 7.2; no usar funciones, sintaxis ni dependencias introducidas en versiones posteriores.
- Antes de entregar cambios PHP, validar los archivos modificados con `php -l` usando PHP 7.2 o mediante el check de GitHub configurado para esa versión.
